# Fonts

TT Hoves Pro Trial (TypeType), four weights, in `woff2` + `woff`:

| File | Weight |
| --- | --- |
| `TT_Hoves_Pro_Trial_Regular.*`  | 400 |
| `TT_Hoves_Pro_Trial_Medium.*`   | 500 |
| `TT_Hoves_Pro_Trial_DemiBold.*` | 600 |
| `TT_Hoves_Pro_Trial_Bold.*`     | 700 |

Copied from the trial download (`TT-Hoves-Pro-Trial-3-200/TT Hoves Pro Trial
3-200/`). The `@font-face` rules are in `../../src/app.css`; renaming a file
means editing those rules and rebuilding with `npm run css`.

Italics and the other weights (Hairline … Black) are in the download but are not
used by the app, so they are not copied here.
